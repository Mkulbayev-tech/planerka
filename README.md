# Planerka — семейный планировщик расходов

Реализация макета Claude Design `budget-planner-v2.dc.html` (исходники макета — в `design/`) на Vite + React.
Приложение умеет работать в двух режимах:

- **Локальный демо-режим** — без настройки: один пользователь, данные в браузере, демо-сценарий из макета.
- **Общий семейный бюджет** — вход по почте, два (и больше) участника видят одни и те же траты, задачи, цели и доходы; обновления приходят сразу. Данные хранятся в Supabase (бесплатный тариф), свой сервер не нужен.

## Быстрый старт (демо)

```
npm install
npm run dev
```

## Общий семейный бюджет: настройка за 15 минут

1. Зарегистрируйтесь на [supabase.com](https://supabase.com) и создайте проект (Free).
2. Откройте **SQL Editor → New query**, вставьте содержимое файла `supabase/schema.sql` и нажмите **Run**.
3. **Authentication → Providers → Email**: включён по умолчанию. Чтобы вход работал по коду из письма, откройте
   **Authentication → Email Templates → Magic Link** и добавьте в текст письма строку `Ваш код: {{ .Token }}`.
   Без этого вход работает по ссылке из письма.
   Встроенная почта Supabase отправляет всего несколько писем в час. Если письма не приходят, подключите свой SMTP
   (**Authentication → SMTP Settings**, например бесплатный тариф Resend).
4. **Authentication → URL Configuration**: в **Site URL** укажите адрес, где будет опубликовано приложение
   (например `https://planerka.vercel.app`), для локальной проверки добавьте `http://localhost:5173` в **Redirect URLs**.
5. **Project Settings → API**: скопируйте `Project URL` и `anon public` ключ в файл `.env`:

   ```
   VITE_SUPABASE_URL=https://xxxx.supabase.co
   VITE_SUPABASE_ANON_KEY=eyJ...
   ```

6. Соберите и опубликуйте статику:

   ```
   npm run build
   ```

   Папку `dist/` можно выложить на Vercel, Netlify или GitHub Pages. На Vercel/Netlify достаточно подключить репозиторий,
   указать команду сборки `npm run build`, папку `dist` и добавить те же две переменные окружения в настройках проекта.

7. Первый участник входит по почте, нажимает «Создать семейный бюджет» и находит **код приглашения** в разделе «Ещё».
   Второй входит по своей почте и нажимает «Присоединиться по коду».

На телефоне откройте ссылку в Safari/Chrome и выберите «Добавить на экран Домой» — приложение будет работать как обычное.

## Что где лежит

- `src/lib/dates.js` — даты: зарплатный период (с N-го числа), неделя, русские подписи.
- `src/data.js` — категории, темы, форматирование сумм, демо-данные.
- `src/model.js` — расчёт всего, что показывают экраны и виджеты (`derive(state, now)`).
- `src/store.jsx` — состояние, действия, вход, подписка на обновления.
- `src/backend/` — хранилища: `local.js` (браузер) и `supabase.js` (общий бюджет). Выбор — по переменным окружения.
- `src/screens/` — экраны; `src/components/SheetHost.jsx` — формы задач, целей, доходов, лимитов.
- `src/widgets/WidgetsBoard.jsx` — доска iOS-виджетов; `src/ios-frame.jsx` — рамка iPhone из макета.
- `supabase/schema.sql` — таблицы, права доступа (RLS) и функции для Supabase.

## Как устроены данные

- Период = зарплатный цикл: с «начала месяца» (по умолчанию 5-е число) до того же числа следующего месяца.
  Баланс «можно потратить» = зарплата + разовые доходы за период − траты за период.
- Тёмная тема и напоминания — настройки конкретного устройства; всё остальное общее для семьи.
- Долгое нажатие на задаче открывает редактирование, тап — отмечает выполненной. Тап на трате, доходе,
  цели или категории бюджета открывает карточку с изменением или удалением.
